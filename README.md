# Smart Urban Transport System

A C++ CLI application that simulates and manages an urban public transport
network. The project models the interaction between vehicles, infrastructure,
and passengers, and computes travel times and statistics.

## Features

### Fleet and Infrastructure Management
- **Multimodal System:** Support for `Bus`, `Tram`, and `Metro` vehicles, each
  with its own operating logic.
- **Controlled Instantiation:** A `VehicleFactory` creates vehicle objects in
  an extensible and safe way.
- **Routes and Stations:** Urban routes are defined through `Route` and
  `Station` objects, allowing a realistic model of the transport map.

### Maintenance and Operations
- **Maintenance Module:** Tracks technical status, mileage, and the repair
  flow for each vehicle.
- **Ticketing:** Integrated system for issuing tickets, managing their serials,
  and recording collected revenue.
- **Incident Management:** Reports and processes unexpected events (accidents,
  roadblocks, delays) that affect system dynamics.

### Analysis and Persistence
- **Advanced Statistics:** Detailed reports generated by dedicated modules,
  plus the generic `StatisticsSeries` template for data processing.
- **Data Persistence:** Saves and loads the whole system state using external
  text files for simulation continuity.
- **Centralized Logging:** All system events are monitored through the
  `Logger` singleton.

### Error Handling
- A dedicated exception hierarchy (`TransportException` and subclasses)
  provides clear error reporting in the CLI.

## Architecture

- **Vehicle** – abstract base class for all vehicles
- **Bus / Tram / Metro** – concrete vehicle types
- **Route** – a public transport route
- **Station** – a stop served by routes
- **Incident** – unexpected events affecting travel time
- **Dispatcher** – the central domain object coordinating the system
- **Maintenance** – fleet technical status and repairs
- **TicketingSystem / Ticket** – ticket sales and revenue
- **Statistics** – analysis and reporting utilities
- **StatisticsSeries** – generic data-processing template
- **Persistence** – save/load of the system state
- **Logger** – event logging (singleton)
- **VehicleFactory** – polymorphic vehicle creation
- **main.cpp** – the CLI menu

## Building

CMake-based, C++23:

```
cmake -S . -B build
cmake --build build
```

The resulting executable is named `smart_urban_transport`.

## Usage

Run the executable and choose an option from the interactive menu.

For an automated, non-interactive run (also used by CI), pipe the demo input
file to the executable:

```
./smart_urban_transport < demo_input.txt
```
